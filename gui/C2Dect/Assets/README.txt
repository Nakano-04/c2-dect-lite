Iconos propios del mapa de segmentos (opcional).
Suelta aquí tus PNG (fondo transparente, ~64px) y el mapa los usa automáticamente;
si no existen, usa iconos vectoriales/emoji integrados (sin internet, sin fugas).

Nombres reconocidos:
  fw.png       Firewall / borde
  server.png   (reservado: columnas de segmento)
  out.png      (reservado: columna OUT)
  win.png      Sesiones Windows
  lin.png      Sesiones Linux
  android.png  Sesiones Android

No se descarga nada en runtime: todo es local.
